インタラクティブ解説

Google Mapをサイトに埋め込むAPI連携の裏側

1

ステップ1：Google Cloud Platformで準備

すべてはここから始まります。開発者はGoogleが提供するサービス基盤「Google Cloud Platform (GCP)」にアクセスし、地図機能を使うための「プロジェクト」という名の作業部屋を作成します。

👨‍💻 →
☁️ GCPプロジェクト作成
2

ステップ2：地図APIのスイッチをONにする

プロジェクトの中で、「Maps JavaScript API」を探し、そのサービスの利用スイッチを「有効（ON）」にします。これで地図機能を使う準備が整います。

Maps JavaScript API

3

ステップ3：秘密の「APIキー」を取得する

APIを有効にすると、Googleは「APIキー」と呼ばれる、あなた専用の長い文字列を発行してくれます。これは、サービスを利用するための「合鍵」のようなものです。

認証情報ページ
→
🔑 AIzaSy...Abc123

このキーはパスワードと同じくらい大切に扱います！

4

ステップ4：APIキーに「鍵」をかける（保護）

取得したAPIキーが第三者に盗まれて悪用されないように、「自社のウェブサイトから使われたときだけ有効」という制限をかけます。これで、万が一キーが漏れても不正利用を防げます。

🔑 + 🌐 = 🔒

許可するサイト: https://example.com/*

5

ステップ5：ウェブサイトにコードを記述する

開発者は自社サイトのHTMLファイルに、地図を表示する場所を確保し、APIを読み込む魔法の呪文（scriptタグ）とAPIキーを追加します。

<!-- 地図の表示場所 -->
<div id="map"></div>

<!-- Googleに地図利用をお願いするコード -->
<script async
  src="https://maps.googleapis.com/maps/api/js?key=ここにあなたのAPIキー&callback=initMap">
</script>
6

ステップ6：ユーザーがサイトにアクセス！

ユーザーがあなたの会社のウェブサイトを訪れます。ここからAPI連携が自動的に始まります。

👤 → 🌐 → 🖥️
7

ステップ7：裏側での自動連携

ユーザーのブラウザがコードを読み込み、APIキーを持ってGoogleのサーバーに地図データをリクエスト。Googleはキーとサイトを検証し、問題なければ地図データを返します。

🌐 ブラウザがコードとAPIキーを読む
🔑 + 🌐 → ☁️ Googleにリクエスト
☁️ キーとサイトを検証: OK! ✅
☁️ → 🗺️ 地図データを返却
🌐 → 🖥️ ブラウザが地図を描画
8

ステップ8：表示完了！

すべての連携が正常に完了し、ユーザーの画面にインタラクティブなGoogle Mapが正しく表示されます。
